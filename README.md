# Eventify

Eventify is a desktop event management application built with JavaFX and SQLite. It streamlines the event management workflow for organizers while providing an intuitive portal for participants to discover events and track activities.

---

## Features

### Organizer Tools
* **Event Management:** Create, edit, and delete events with capacity enforcement.
* **Dashboard & Analytics:** View key statistics, participant registrations, and export event data.
* **Attendance & Tasks:** Track attendee participation and assign point-based tasks.
* **Leaderboard & Scheduling:** Real-time participant ranking and public holiday integration.

### Participant Tools
* **Account Portal:** Secure user registration and login system.
* **Event Discovery:** Browse upcoming events, register, or cancel registrations.
* **Schedules & Tasks:** View event agendas and update assigned task progress.
* **Live Leaderboard:** Track personal and overall rank performance.
